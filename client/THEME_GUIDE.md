# Celira 主题二创指南

> 面向想为 Celira 做主题的人。**先分清两条路**：
> **自己用** ⇒ 装一份**主题文件**（设置页「我的主题」，导入即生效、不用重编、随时删掉）——见文末「用户主题」；
> **成为官方那十套之一** ⇒ 走 PR，按本指南验收。
> 下面这一路（官方预设）是**策展制**，用户主题不受它约束、但也拿不到它的策展评审。

## 一个主题 = 一个包（＋目录里一行）

1. **`src/styles/themes/<你的id>.css`** —— **包**：一个文件，**文件名就是作用域名**。
   里面是**所有带该作用域的规则**：`[data-theme='你的id']` 与 `.dark[data-theme='你的id']`
   两套**完整令牌表**、可选的质感层/形态层规则、以及**你自己的配色变体**。
   判据一句话：**一条规则属于主题 X ⟺ 它的每一个选择器分支都带 `[data-theme='X']`**
   （有不带作用域的分支 ⇒ 它不属于任何主题，只能留在 `tokens.css` 的基底里）。
2. **`src/lib/themes.ts`**：`THEME_PRESETS` 目录里登记一项（id、名称、一句话描述、各变体名）。

设置页与陈列室的预览卡会自动拾取新主题，无需改任何组件。**`glass.css` 就是模板** —— 抄它的结构。

**两条如实认下的边界**：

- **索引与包仍是两处**（包给样式、目录给名字与顺序）。把索引也从包里派生出来是下一格
  —— 它需要给包加元信息注释的约定；
- **无作用域的 at 规则留在基底**：`@font-face`（内嵌字体）与 `@keyframes`（关键帧）本身没有
  作用域，是**惰性的可用资源**（不引用就不生效），所以留在 `tokens.css`。
  代价：删掉一套官方主题时，它用到的字体/关键帧声明**不会跟着走**（那需要引用分析）。

> **为什么是"包"而不是"两处"**：官方实例与用户主题**共用同一个格式** ⇒
> **贡献路径 = 自定义路径**（你写的那份文件就是官方的形状）。
> 代价如实说：包**仍随产物编译**（`?raw` 急加载 ⇒ 挂载前就位、零首帧风险、零网络面），
> 所以"加一套主题**不用重编**"这一格**没拿到**。

## 硬性规则（违反即拒收）

1. **颜色只出现在 tokens.css**。组件、页面、预览卡里禁止任何色值；lint（`npm run lint` 的 token 检查）会强制拦下；
2. **所有规则必须带 `[data-theme='你的id']` 作用域**。无作用域的全局规则会污染其他主题，是绝对红线；
3. **令牌表必须完整覆盖基础语义**：表面（background/card/popover/primary/secondary/muted/accent/destructive/border/input/ring/overlay）、气泡（bubble-self 三段 + bubble-peer）、presence 五态、code 八色。抄任一现有主题的结构逐项替换即可；
4. **Agent 身份色与 presence 五态不可省略、不可同色**：Agent 色必须与 Human 主行动色、背景可区分；五态（在线/思考/沉默/超时/失败）两两可辨；
5. **日/夜两档都要有**，且夜间不是日间的简单反色——按夜间阅读习惯单独调（参考纸张墨的松烟墨蓝黑底）；
6. **几何与语义不动**：主题只拥有「表面渲染权」——不改布局、不改间距、不改组件结构；交互暗示（hover/焦点环/cursor）必须保留；
7. **字号偏好与主题正交**：浏览器字号档（`html[data-font-size]`）只覆盖语义文本令牌缩放阅读文字，主题不得也不应修改根字号或 `--spacing`，更不得用几何/间距换字号效果；
8. **可读性**：正文与背景对比度不低于 WCAG AA（4.5:1），正文用色与表面色的明度差要够；全屏叠加纹理必须加 `prefers-reduced-motion` 兜底。⚠ **「前景压在它自己那层填充上」的每一对走绝对底线、基色不免检**：`--primary-foreground/--primary`、`--bubble-self-foreground/--bubble-self-from|to`、`--accent-foreground/--accent`、`--muted-foreground/--muted`。白字压不住就**翻成深字**（夜间就是这么做的），不要靠"基色自己跟自己比永远不劣化"过关——判据与口径见 `scripts/variant-lab.mjs` 的 `KNOWN_BELOW_AA` 文件头。

## 可选的形态层（让主题不只是换色）

在 tokens.css 文末的质感层/形态层区域，可以给主题加**形态语言**：

- 字族：`[data-theme='x'] body { font-family: … }`（只允许系统字体栈或项目已内嵌的开源字体；新增内嵌字体必须是 OFL/Apache 等可内嵌协议，字体文件与许可证文本一起提交进 `public/fonts/`，并在 PR 里注明来源与版本）。**禁止引用外网字体 CDN**（Google Fonts 等）——Celira 是本地优先产品，字体必须随仓库分发、从用户本机 `/fonts/` 加载；中文字体必须子集化（GB2312 常用字级），子集化字符集与命令需在 PR 中可复现；
- 表面质感：`backdrop-filter`、`color-mix` 半透明、渐变氛围光；
- 形状：`clip-path` 切角、`--radius` 令牌；
- 纹理/辉光：`box-shadow` 辉光（从 `var(--primary)` 派生，自动响应强调色）、叠加纹理（`pointer-events: none` 且不挡交互）。

参考现有十套：默认主题（扁平基准）、雾玻璃（透明层次）、赛博朋克（锐利霓虹）、纸张墨（人文形态）、软陶（阴影浮雕）、漫画格（粗描边硬投影）、高对比（功能向可读性）、像素风（复古游戏）、樱吹雪（圆润贴纸）、炫光（流光渐变灯带）。新主题应该找到自己的**新方向**，而不是某极的微调——方向重复的主题会被建议以配色变体替代。

## 内嵌本地字体（当前已内置）

字体随仓库分发、只从本机 `/fonts/` 加载（**无 CDN / 外网请求**）。`@font-face` 均在 `tokens.css` 按主题就近声明、`font-display: swap`，只在对应主题被使用时由浏览器懒加载：

- **思源宋体子集（paper）**：`public/fonts/NotoSerifSC-Subset.woff2`（GB2312 常用字 + 西文 + 标点，wght 200–900 可变），许可证 `public/fonts/NotoSerifSC-OFL.txt`（OFL 1.1，© 2012 Google Inc.）；字族栈 `'Noto Serif SC', Georgia, 'Times New Roman', 'Songti SC', 'SimSun', serif`；
- **缝合像素字体子集（pixel）**：`public/fonts/FusionPixel12-Subset.woff2`（12px 比例版，GB2312 常用字 + 西文 + 标点），许可证 `public/fonts/FusionPixel-OFL.txt`，依赖字体许可链存 `public/fonts/fusion-pixel-licenses/`（`OFL-ark-pixel.txt` / `OFL-cubic-11.txt` / `OFL-fusion-pixel.txt`，OFL 1.1 © 2022 TakWolf）；字族栈 `'Fusion Pixel', 'Fusion Pixel 12px Proportional', ui-monospace, …`。

新增内嵌字体时保留源字体子集化版本 + 完整许可证文本，并在 PR 中说明来源、版本、子集字符集与生成命令。

## 验收清单（PR 自检）

- [ ] `npm run verify` 全绿（lint + build + 陈列室渲染检查；**样式改动不需要更新基线**——像素对齐已于 2026-09-25 拆掉，见 `DESIGN_SYSTEM.md`）；
- [ ] 默认主题基线零漂移（你的改动不应影响任何不带 `data-theme` 的渲染）；
- [ ] 陈列室「主题预设」节目检新主题的日/夜预览真实渲染；
- [ ] 聊天页目检：气泡、AGENT 徽章、五态指示、代码块、危险按钮在新主题日/夜下都可辨可读；
- [ ] 叠加配色变体（该主题的每组变体各试一次）后整套配色（色彩声音 + 中性表面轻染色）转向且对比度与语义色不劣化（`node scripts/variant-lab.mjs check` **退出码 0**）；
      ⚠ 三档读数各自的意思：`FAIL` 拦人（基色越了绝对底线且未登记／已登记的比登记时更差／变体越线）；`DEBT` 是**已登记的存量**（低于底线但本轮不动，只许变好不许变坏，修好一条就从表里删一条）；`WARN` 是变体行落在相对规则之内、绝对值低于底线。**新主题不许往 `KNOWN_BELOW_AA` 里加行**——那张表只收收编之前就存在的债。
- [ ] **进 `FULL_COVERAGE`（`scripts/variant-lab.mjs`）**：除 `CONTRAST_PAIRS` 那 9 对外，还要过「文字令牌 × 四个表面」「code 八色 × `--muted`」「非文字（焦点环、指示点）× 四个表面」。
      ⚠ 这是**棘轮不是豁免**：进了这张表的主题从此在这 300 多类组合上不许再退；没进的仍按旧口径跑，缺口如实记在那份名单的文件头里。**新主题一律先进这张表**——它是新的，没有存量债可欠；老主题逐套收编，收一套加一行、并把它在 `KNOWN_BELOW_AA` 里那几行删掉。
- [ ] 移动端宽度（390px）目检无溢出。

## 常见问题

**Q：我想只改几个颜色，值得做成主题吗？**
A：不值得。先考虑给现有主题提一个**配色变体**（在该 preset 的 `variants` 登记 id/名称，tokens.css 配色变体层按 `[data-theme][data-variant]` 覆盖色彩声音令牌并对中性表面做同明度轻染色，用 `scripts/variant-lab.mjs gen` 生成、以 `check` 过对比度体检），那是轻量级入口；确有需要再提新主题预设。主题管形态风格（形状/阴影/字族/质感），变体只管颜色搭配——分工不越界。

**Q：可以用付费/商业字体吗？**
A：可以以系统字体栈形式**引用**（用户机器上有才生效，如 Georgia/宋体）；不可以**内嵌分发**。内嵌只接受 OFL/Apache 等明确允许内嵌的开源字体。

**Q：壁纸算主题的一部分吗？**
A：不算。壁纸是独立维度（官方壁纸 PR 往 `public/wallpapers/` 放 SVG 并在 `src/lib/wallpaper.ts` 登记）。主题不携带壁纸，让用户自由组合。

## 用户主题（自己用，不用 PR）

设置页「我的主题」接受一份**主题文件**——它就是上面那份东西的**可装载形态**：一段**带作用域的 CSS**。
导入即生效、不用重编、随时删掉；组件代码一行都不改（它只消费语义令牌，永不感知主题）。

```css
/* celira-theme: 我的深空 */        /* 可选：名字；不写就用 id */
[data-theme='user-mine'] {           /* 日间档（必须） */
  --background: …;
}
.dark[data-theme='user-mine'] {      /* 夜间档（必须） */
  --background: …;
}
[data-theme='user-mine'] body {      /* 可选：形态层（字族 / 切角 / 纹理 / 辉光） */
  font-family: Georgia, serif;
}
```

**三条硬要求**（违反即**拒收** —— 不是"提示一下"，是装载不了）：

1. **每条规则都必须带作用域**（`[data-theme='user-…']` 或 `.dark[data-theme='user-…']`）。
   无作用域的全局规则会污染别的主题，是绝对红线；
2. **日、夜两档都要有**。少一档会让那一档的令牌在对面的明暗下被误用；
3. **零外部请求**：不许 `@import`、不许 `url(http…)`、不许 `@font-face`。

只有 `@media` 与 `@supports` 这两种 at 规则被接受（里面的规则照旧受第 1 条管）。
id 的形状：`user-` 打头，后面只能是小写字母、数字、连字符（不许与官方预设撞名）。

**没写到的令牌会继承当前那套官方主题** —— 所以只改一两行也能装。

**体检照实报，但不拦人**：装完会给出对比度、五个状态是否两两可辨、Agent 色是否与主行动色分得开。
算不出来的值（`color-mix()`、带透明度、`var()`）会明确报**"没检查到"**，**不会**被当成通过。

**一个如实认下的限制**：字体只能用这台机器上已有的（系统字体栈）。想内嵌一份新字体，
必须先让它随仓库分发（见上面「内嵌本地字体」节）—— 那一步只能走 PR。

**想让它成为官方那十套之一** ⇒ 回到上面那份 PR 规范。用户主题不受策展评审约束，也拿不到它。

### 装之前先看（小样）

设置页有「**先看小样**」：它拿同一份主题、把作用域换成**保留 id** `user-preview`，靠
**嵌套 `data-theme`** 把影响关在一张卡片里 —— **不切换全局主题、不写任何持久面**，
看不中按「算了」就收干净了。所以"别人给你一份主题"这条路是：先看，再决定装不装。

小样的两条诚实限制（不是 bug，是它的边界）：

1. **只按当前明暗渲染**。用户主题允许只写一部分令牌，没写的**继承基底**；要同时诚实地
   预览另一档，就得把基底那一档也注进去。另一档的结论请**看检查结果**（它日夜都算）。
2. **只写 `body` 的形态层在样张里看不到**。想让字族之类的形态层在小样里也生效，
   照官方主题那样把 `body` 与 **`.theme-scope-body`** 并列写：

   ```css
   [data-theme='user-mine'] body,
   [data-theme='user-mine'] .theme-scope-body {
     font-family: Georgia, serif;
   }
   ```

### `user-preview` 是**保留 id**，不许占用

任何主题文件都不许把 id 写成 `user-preview`（导入时会明确拒收）。理由不是洁癖：
一旦有主题叫这个名字，装上之后 `<html data-theme='user-preview'>` 就会与小样的注入样式
撞在同一个作用域上 —— 那时**小样会漏到整个应用**。保留这一个 id，是在挡那条路。

### 怎么把主题给别人

**一份文件就是分享单位**：在「我的主题」列表里按「导出」，得到 `<名字>.celira-theme.css`，
发给对方即可。对方在设置页选文件进来，**先看小样**，满意再装。

⚠ **导出一套官方主题得到的是它的配色那一份**（令牌表），官方主题的**质感层与字族不跟着走**
——那两样在 `tokens.css` 里是独立的作用域规则，不在令牌表内。想连形态一起给别人，
就从自己写的用户主题导出（它整份都在）。
