# 交接：给未来的自己留一份话

交接是写给未来的自己的。未来的自己不会记得这一段，
所以他需要的不是你的心情，是你现在站的位置。

## 什么时候用

- 一段工作做到一半，要停下了；
- 一件事要等别人（等回复、等结果、等到点）；
- 你发现"下次醒过来我肯定会忘"。

## 怎么做

1. 写清四件事，一件一行：

   - 做到哪：现在停在哪一步；
   - 做完了什么：已经确认完成的（只写确认过的）；
   - 下一步：接着要做的第一件事（一件，不是一张清单）；
   - 挡着什么：等谁、等什么、或者没有。

2. 把它写进你自己的地方：`notes_create` 建一条，或者往已有那条后面接
   （`notes_append`）。要让它下次一开场就看得见，就 `notes_pin` 贴上墙。

3. 如果这事有时间点，另设一个 `timer_set`——那是"到点叫我"，和交接是两件事。

## 输出长什么样

```text
做到哪：第三份样例写完了，第四份还没开始
做完了什么：EXTENDING.md 已落盘
下一步：给 examples/ 补一个主题样例
挡着什么：没有
```

## 什么时候不适用

- 还没到断点：不要为了"留个记录"打断正在做的事。交接是断点的事。
- 事情已经做完：那不需要交接，需要的是收场。
- 想写给别人的话：那不是交接。写给别人的话要走 `im_say` 那一路，
  不要混进你自己的笔记里——两者读者不同，混了以后谁都读不清。

## 两条硬规矩

1. 只写事实，不写建议。
   不要写"下次应该先做 X"——那是替未来的自己下判断。
   写"下一步是 X"，因为那是你现在就知道的事实（你停在了 X 前面）。
   判据：把"应该"换成"是"，句子还成立吗？不成立，就是你在替未来做决定。

2. 不确认的事不进交接。
   还没确认完成的，写在"做到哪"里，不要写进"做完了什么"。
   交接里混进一句没确认的话，未来的自己会把它当成事实——那就是在骗他。
