# Celira Runtime：沙箱为什么**不带**网络

> 状态：**已裁决**（2026-10-23，主人）。承接 `SANDBOX_IDENTITY_DECISIONS.md`（写边界）与
> `terminal=sandbox` 的实现。本文回答的是「要不要给沙箱开一张允许名单」，结论是**不开**。

## 1. 一句话裁决

**沙箱永远不带网络。出网是一条独立的能力，不是沙箱的一个开关。**

需要读网页 ⇒ 走 `web` 窗（`web_search` / `web_fetch`，宿主侧执行，有档位、有界、有审计）；
需要装东西 ⇒ 宿主预置，或将来单独的 provision 能力。
**`terminal=sandbox` 的断网是硬边界，不提供 `network=allowlist` 这一档。**

## 2. 三条理由

### 2.1 技术上：没有 root、没有 userns 时，「按目的地过滤」没有诚实的实现

| 机制 | 能不能按目的地 | 问题 |
|---|---|---|
| 经典 seccomp BPF | **不能** | `connect()` 的目的地在指针里，BPF 只看得见系统调用号与标量参数 |
| seccomp user-notify | 能（读到 `sockaddr`） | 要一个监管线程、要处理 **TOCTOU**（批准之后子进程改掉 `sockaddr`），复杂度和风险都实打实 |
| Landlock 网络（ABI 4） | **只按端口** | 「允许 3128」等于允许**任何主机**的 3128——那不是允许名单，是留了一扇窄门 |
| `LD_PRELOAD` / 代理环境变量 | 看起来能 | **建议，不是边界**：静态链接、Go、直接发 syscall 的二进制全绕过去 |

⇒ 今天能兑现的只有两种：**全断**，或者**全通**。中间那一档没有可靠的内核支撑。
给一个「看起来像允许名单」的东西，比断网更危险——它把「出不去」换成了「大概出不去」。

### 2.2 产品上：出网已经有一条受控通道

`web` 窗的两条动词是**宿主侧**执行的，且已经带着一整套纪律：

- `WebTier` 三档（`off` / `fetch` / `full`），`off` 连这扇门都不摆；
- 单次回执 ≤ 64 KiB，超限**拒绝不截断**；单次 30 秒窗口；**一次调用恰好一次请求**（零重试，按次计费）；
- 失败词表封闭（`transport-unreachable` / `timeout` / `credential-absent` / …）；
- 每一次调用都是**一条动作事实**，账本里查得到。

在沙箱里再开一条「任意 TCP」，等于给这条通道开一个后门，还绕开它的上限、词表与审计。

### 2.3 审计上：沙箱里的出网记不下来

`web_*` 记的是「谁、什么时候、取了哪个地址」；沙箱里一条 `curl` 记不下来目的地——
我们只能记「跑过一条命令」。**能记下来的才配叫允许名单**，记不下来的叫事后猜。

## 3. 那「装依赖」怎么办（明确不在这一刀）

三条路，按代价从低到高：

1. **宿主预置**（今天）：工具链在安装期准备好，沙箱里只用已有的——这条已经把 `git` / `node` /
   `python` 这类常见需求覆盖掉了；
2. **离线包**：宿主下载（走 `web` 或安装器），放进环境根，沙箱内离线安装——写面仍然只有环境根；
3. **provision 能力**（将来，单独裁决）：宿主执行、要授权、要审计。**不是**在沙箱里开网。

## 4. 什么会推翻这条裁决

要同时满足三条，才值得另起一篇裁决：

1. **不需要 root、不需要 user namespace**（否则不如直接用 bwrap 的 netns）；
2. **能按目的地过滤**，不是按端口，也不是靠环境变量；
3. **有真实消费者**，并且能写出「绕过测试」——证明静态链接的二进制、直接 syscall 都过不去。

在那之前，**不允许**用 `--share-net`、代理环境变量、`LD_PRELOAD` 或「按端口放行」作为近似实现。
近似实现在文档上叫 allowlist，在攻击面上叫 egress。

## 5. 负空间（这一条与它相邻的几格，照实写）

- **`web` 窗不保证对面**：抓取走厂商 API，私网、重定向、内容类型都不归我们管（`web_app` 已登记）；
- **沙箱内没有 DNS**：`getaddrinfo` 直接失败（`EAI_AGAIN`），这是断网的直接后果；
- **断网不是防火墙**：seccomp 拒的是「建 IP 套接字」这个动作；`AF_UNIX` 照旧通（agent / 会话总线
  的 socket 仍可达），`--unshare-net` 那一支则是「没有网卡」。

## 6. 防止悄悄加回来

- 过滤器的形状是被测试钉住的：`seccomp::FILTER` 里 `AF_INET` / `AF_INET6` 必须落到
  `RET ERRNO|EACCES`，`io_uring_setup` 同理（`the_filter_refuses_ip_sockets_and_nothing_else`）；
- bwrap 那支的 argv 固定含 `--unshare-net`（`the_bwrap_plan_pins_the_required_isolation_flags`）；
- 谁要加「给沙箱开网」，先改本文——**加一档 `network` 不是加一个参数，是换一份承诺**。
