## 一、判据句（23 条）

1. Agent 的病是**清醒时无法自主控制焦点与可达性、每次清醒期结束即全部遗忘**——不是短期记忆差。
2. 视野里的**无关物**越多越糟。
3. **没被用过的存储不是记忆。**
4. **交接不可由世界重建的东西。**（"为什么"是最典型的一类；可重建的不交接 = 冗余失真）
5. **不能拒绝工作 = 在上班；不能发起工作 = 在待命。两者都不是自主状态。**（能力检查，非意图猜测）
6. **记忆会淡出，自我不会。**
7. **未用 → 可达性降级，绝不 → 删。** 可达性降级不是存在性降级。
8. **给目录不给判断 · 给名单不给排序 · 给事实不给亲疏 · 给见证不给担保。**
9. 系统补能力缺口，**不替认知判断**。代笔按内容定罪：聚合事实清单合规，语义叙述越界。
10. **Agent 看不见的规则不算环境。**
11. 连续性的单位是**未完结事项**，不是 session（锚点：ContinuitySnapshot outstanding 段 + handoff_notes）。
12. 判错纪律：**判据句 → 实现单向主导**；下行能判错；上行能直述且不脸红（兜底抓手豁免，改用审计检验）。
13. **系统必须让 Agent 的遗忘对自己可见。**（空槽：系统给机械事实清单 + 空槽，内容永远归 Agent）
14. **承诺必须落在双方都能看见的地方**，谁都不许只记在自己脑子里。
15. **会随行动范围而变的是处境，跨行动范围恒常的是 Self 的候选。**
16. **教育效果 = 硬上限的持久性 × Agent 的记录意愿。** 权利必须由不可绕过的硬上限传导代价。意愿三脚：先天习惯 × 环境可见 × 触达上限的痛感（经验赌注，待 Phase 2 实验裁决）。
17. **Agent 造成的环境变化必须对 Agent 可见**——否则"Agent 对自己的行为负责"是空话。（持有物：系统摆清单带年龄，不阻止、不提醒；注入按性质分类不按重要性分级）
18. **欠债折，资产降级。** 空槽是欠债：计上限，触达上限 = 最老折进目录（不删）；它是唯一允许折到看不见的东西。
19. **来源是机械事实**：系统建来源索引，只记引用，不给亲疏。关系网的替代是索引，不是器官。
20. **热度给主体看，不替主体排序。** 高频长存的条目是 Self 的候选——认定归 Agent。（呈现中立；candidate/promotion 协议层拆开）
21. **视野预算的分配：硬上限归系统 · 折叠归机械（判据只许机械事实）· pin 归 Agent。** 三方都不是"系统判断重要性"。
22. **账只追加，版面可重写。** 账改一次，她就不是她了；版面不重写，她就僵死了。
23. **首屏只摆事实，不摆判断。** "属于谁、从哪来、什么时候、什么状态"可以摆；"这是你最关心的""建议先处理它"不许摆。

## 二、判错纪律（判据 12 的操作化）

1. **单向主导：判据句 → 实现。** 实现可以倒逼判据句*修正*（判据句彼此打架 = 判据没想清），但工程便利性不得*发明*判据。
2. **下行检验**：每条判据句必须能说出"代码里什么样算违反"。说不出来 = 装饰，没长牙。
3. **上行检验**：每个 Agent 看得见、与 Agent 交互的工程机制，必须能用准确的普通话说清它是什么且不脸红。说不清 = 孤儿机制，大概率加多了。
   - **豁免**：兜底抓手（幂等、审计、隔离）属"看不见但在保护 Agent"，不需要直述，但需要**审计检验**代替。

## 三、概念 ⇄ 工程锚点定义表

| 概念 | 工程锚点 | 判据句（怎么算违反） |
|---|---|---|
| 清醒期 | Run | 无限/无预算的 Run |
| 自主状态 | 无行动范围的合法状态（醒着可什么都不做，no_reply 即合法收场） | 不能拒绝/发起工作 = 系统的状态；没有行动范围就什么都做不了 = 囚室 |
| 行动范围 | Run 级绑定 + navigate 惰性生效（开场快照属插槽机械内容；Session 为实现细节） | 把自主状态做成某种行动范围；fork 复印自我；把内容做成核心对象（核心是装配通道，不是内容） |
| 视野 | Context | 无关物越多越糟；视野外的规则不算环境 |
| 目录 | 状态栏注入（可折叠） | 带排序带建议 = 认知代劳 |
| 记录 | Memory | 系统写语义摘要 = 越界 |
| 已算结论 | 决策日志/已算好的结论 | 交接可重建的 = 冗余失真；不可重建的没交接 = 死亡 |
| 空槽 | journal 机械事实清单 + Key Decisions 段 | 系统填槽 = 代笔；无槽 = 遗忘不可见 |
| 未完结事项 | ContinuitySnapshot outstanding 段 + handoff_notes | 无锚点的"未完结事项" = 不可执行 |
| 持有物 | 状态栏（进程/端口/自 arm 闹钟清单，带年龄） | 系统阻止 Agent 行动 = 过度保护；系统说"你忘了" = 判断 |
| 来源索引 | 记忆的"因谁而起"引用（机械事实） | 系统给亲疏 = 越界 |
| 热度 | 被读次数/上次读取（机械统计，给主体看） | 用于自动排序 = 越界 |
| 见证 | im 服务端 公共事实（公共消息主链） | 承诺只记在自己脑子里 = 无见证 |
| 先天特质 | 系统提示词 | 性格写进提示词 = 钉死 |
| **首屏** | 她每次醒来第一眼看到的那一屏，**三处来源**：Run 级插槽（处境链那批）＋ 首轮 Turn 级插槽（动作目录）＋ **不经插槽的系统消息静态头**（出厂说明）。正名与逐块清单见 `AGENT_VOCABULARY.md` §9 与 `agent/README.md` | 把"觉得重要/建议先做"摆进去 = 认知代劳；加一块内容能从三处中的任一处漏进去而没人看见 = 无权威 |
| **账 ／ 版面** | 账＝地基持久层（只追加的 Trace/Fact ＋ records/pins）；版面＝首屏与各显示面（可重写，坏了就重建） | 对账做有损摘要或自动改写 = 篡改记忆；把版面做成不可重写 = 僵死 |

## 四、代笔定罪标准（判据 9 的操作化）

**按内容定罪，不按作者。** 三层分离：

- **Source**：原始事实（journal、git、行动范围时间轴、artifact）——合规。
- **Derived**：带来源引用的派生结构（聚合事实清单、引用链），每个节点可指回 Source——合规。
- **Interpretation**：无来源的语义叙述（替主体解释意义、动机、重要性）——越界。

**可验证性就是合规线：每个 Derived 节点都能指着自己的来源。**

## 五、记忆器官的宪法职责清单

Persistence（关键外部状态不无故消失）/ Addressability（Agent 有办法找到）/ Recoverability（醒来能重建工作状态）/ Provenance（每条信息知道来自哪里）/ Boundaries（系统的判断不得伪装成 Agent 的记忆）。

连续性是**数据**的属性，不是工具的属性：宪法保护地基持久层——Agent 写下的记录、pin 与游标；不保护工具。卸载 app 不等于删数据。
